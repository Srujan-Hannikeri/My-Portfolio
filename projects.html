  • Simon Say's Game

    (Practice Project)

    HTML | CSS | JavaScript

    Key Features:
    • Interactive Simon Says memory game with four colorful buttons.
    • Random color sequence generation for each level.
    • User input validation against the generated sequence.
    • Level progression with increasing difficulty.
    • Keyboard press to start or restart the game.
    • Visual button flash animations for game and user actions.
    • Instant game-over detection with restart option.
    • Simple, responsive, and user-friendly interface.

    Description:
    Simon Says is a fun memory-based game where players must observe and remember a sequence of colored button flashes. The game begins when the user presses any key, after which a random color is highlighted. With each new level, another color is added to the sequence, making it progressively more challenging. Players must repeat the exact sequence by clicking the colored buttons in the correct order. If the sequence is entered correctly, the player advances to the next level. An incorrect click ends the game, displaying the final score and allowing the player to restart by pressing any key.

  • Currency Convertor

    (Practice Project)

    HTML | CSS | JavaScript

    Key Features:

    • User-friendly interface with amount input and country selection dropdowns.
    • Automatic country flag updates based on the selected currency.
    • Displays the latest exchange rate between selected currencies.
    • Swap icon for easy switching between source and destination currencies.

    Description:
    The Currency Converter is a web application that enables users to convert an amount from one currency to another using the latest exchange rates. Users can enter an amount, select the source and target currencies from dropdown menus, and instantly view the converted value along with the current exchange rate. The application dynamically updates country flags based on the selected currencies and provides an intuitive interface for quick and accurate conversions. Built using HTML, CSS, and JavaScript, it offers a responsive design and seamless user experience across different devices.
